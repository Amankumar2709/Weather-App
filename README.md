🌐 Weather App Landing Page – Project Overview
This is a responsive weather application landing page built using modern frontend technologies and deployed on Netlify.

🔧 Tech Stack Used
HTML5 & CSS3: For structuring and styling the UI with a clean, user-friendly design.

JavaScript (ES6+): For adding interactivity and handling logic.

React.js: Utilized as the core framework to manage UI components and state efficiently.

OpenWeatherMap API: Integrated to fetch and display real-time weather data dynamically.

Responsive Design: Fully optimized for all screen sizes (mobile, tablet, desktop) using media queries and flex/grid layouts.

Netlify: Used for seamless deployment and hosting of the project.

💡 Key Features
Real-time weather information fetched via API

Clean and modern UI/UX

Responsive layout across all devices

Smooth navigation and interactions
